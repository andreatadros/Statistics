Homework 6 — Statistical independence, contingency tables and the χ² test

Statistics — starting from the raw records of a bivariate dataset (X, Y), the page builds the contingency table, the marginal and conditional frequencies, and the table of the frequencies we would expect if X and Y were independent. The distance between the two tables is the χ² statistic, from which we get a p-value and a verdict. The p-value is then checked by simulation, and the last part recalls the theory and the difference between association and causality. Everything is computed live in your browser.

Part 1 — The bivariate dataset

A bivariate dataset is a list of n statistical units; for each unit we record two categorical variables, X and Y. Choose one of the datasets below. The two simulated ones come from a population in which the strength of the dependence is set by λ:

  • with probability 1 − λ the unit gets X and Y drawn independently, each from its own distribution;
  • with probability λ the unit gets X at random and then the value of Y that “goes with” that X (for example: brute-force attacks hit SSH, SQL injections hit the database).

So λ = 0 means X and Y are independent by construction, and larger λ means stronger dependence. With the third option you can paste any dataset of your own, one unit per line.

Part 2 — Contingency table, marginal and conditional frequencies

Joint absolute frequencies nᵢⱼ (the contingency table)

nᵢⱼ = number of units with X = xᵢ and Y = yⱼ. The last column holds the row totals nᵢ. = Σⱼ nᵢⱼ and the last row the column totals n.ⱼ = Σᵢ nᵢⱼ: these are the marginal distributions of X and of Y. The dot means “summed over that index”.

Joint and marginal relative frequencies fᵢⱼ = nᵢⱼ / n

Conditional frequencies of X given Y: f(xᵢ | yⱼ) = nᵢⱼ / n.ⱼ

Each column is the distribution of X inside one group of Y and sums to 1 (the “column profiles”). The last column is the marginal distribution of X, for comparison.

Conditional frequencies of Y given X: f(yⱼ | xᵢ) = nᵢⱼ / nᵢ.

Each row is the distribution of Y inside one group of X and sums to 1 (the “row profiles”). The last row is the marginal distribution of Y.

The column profiles, side by side

Under independence, knowing Y tells us nothing about X: every bar would look like the last one (the marginal of X), up to sampling noise. Bars that look clearly different from each other are the visual sign of dependence.

Part 3 — Expected frequencies and the χ² statistic

Expected frequencies under independence

If X and Y were independent, the joint frequency would be the product of the marginal ones, fᵢⱼ = fᵢ. · f.ⱼ. Multiplying by n gives the count we would expect in each cell:

n*ᵢⱼ = n · (nᵢ. / n) · (n.ⱼ / n) = nᵢ. · n.ⱼ / n

The expected table has the same totals as the observed one; only the inside changes.

Contributions to χ²

Each cell contributes its squared gap from the expected count, scaled by the expected count:

χ² = Σᵢ Σⱼ (nᵢⱼ − n*ᵢⱼ)² / n*ᵢⱼ

Red cells hold more units than expected under independence, blue cells fewer. The colour is stronger when the standardised residual (nᵢⱼ − n*ᵢⱼ) / √n*ᵢⱼ is larger in absolute value (it is saturated at ±3).

Part 5 — Same association, more data

Suppose we observed exactly the same proportions fᵢⱼ on k times as many units. Every count is multiplied by k, so every term (nᵢⱼ − n*ᵢⱼ)² / n*ᵢⱼ is multiplied by k as well:

χ² = n · Σᵢ Σⱼ (fᵢⱼ − fᵢ. f.ⱼ)² / (fᵢ. f.ⱼ) = n · φ²

χ² and the p-value measure the evidence against independence, and evidence grows with n. Cramér’s V depends only on the proportions, so it measures the strength of the association. A tiny association becomes “significant” with enough data, and a strong one can go undetected in a small sample.

Part 6 — Theory

Independence in probability

Two events A and B are independent when

P(A ∩ B) = P(A) · P(B)   ⇔   P(A | B) = P(A)   (when P(B) > 0)

so learning that B happened does not change the probability of A. Two discrete random variables X and Y are independent when this holds for every pair of values:

P(X = xᵢ, Y = yⱼ) = P(X = xᵢ) · P(Y = yⱼ)    for all i, j

The joint distribution factorises into the product of the marginals. Equivalently, the conditional distribution of X given Y = yⱼ is the same for every j, and equals the marginal of X; the same holds with X and Y exchanged, because independence is symmetric. In general (also for continuous variables) the condition is FX,Y(x, y) = FX(x) · FY(y) for all x, y.

Independence implies E[XY] = E[X]·E[Y], so Cov(X, Y) = 0. The converse is false: if X is uniform on {−1, 0, 1} and Y = X², then Cov(X, Y) = E[X³] − E[X]·E[X²] = 0, yet Y is a function of X. Zero correlation only rules out a linear relation; independence rules out every relation.

Independence in statistics

In statistics we do not know the probabilities: we have n observed units. The empirical version of the definition is that X and Y are statistically independent in the data when the joint relative frequencies factorise:

fᵢⱼ = fᵢ. · f.ⱼ   ⇔   nᵢⱼ = nᵢ. n.ⱼ / n = n*ᵢⱼ   ⇔   f(xᵢ | yⱼ) = fᵢ. for all i, j

that is, all the conditional profiles of Part 2 are equal to the marginal one. This almost never holds exactly (n*ᵢⱼ is usually not even an integer), even when the population is independent, because the sample adds random noise. So the statistical question is different: are the deviations nᵢⱼ − n*ᵢⱼ larger than what sampling alone would produce? This needs an index (how far the table is from independence) and a test (is that distance surprising).

The χ² index and the χ² test

χ² = 0 exactly when the observed table equals the expected one, and grows as the two tables move apart. Pearson’s test uses it to decide between

H₀: X and Y are independent in the population    vs    H₁: they are dependent

Under H₀ and for large n, χ² approximately follows a χ² distribution with (r − 1)(c − 1) degrees of freedom, where r and c are the numbers of categories of X and Y. The degrees of freedom count the cells that are free to vary: the table has r·c cells, but the expected table is built from the r − 1 free row proportions, the c − 1 free column proportions and n, so r·c − 1 − (r − 1) − (c − 1) = (r − 1)(c − 1). The p-value is P(χ²df ≥ observed χ²): the probability, if H₀ were true, of a table at least as far from independence as ours. If p < α we reject independence; otherwise the data are compatible with independence. That is not a proof of independence: with few data a real but weak dependence may go unnoticed.

The approximation is considered reliable when the expected counts are not too small (the usual rule: all n*ᵢⱼ ≥ 1 and at most 20% of them below 5). Part 4 avoids the approximation by simulating the distribution of χ² under H₀.

Because χ² grows with n (Part 5), the strength of the association is measured by Cramér’s V, which rescales it to [0, 1]:

V = √( χ² / (n · (min(r, c) − 1)) )

V = 0 exactly when the table shows perfect empirical independence, and V = 1 when the association is perfect (one variable determines the other, if r = c). As a rough guide, V below 0.1 is negligible, 0.1–0.3 weak, 0.3–0.5 moderate, above 0.5 strong.

Association is not causation

Rejecting independence tells us that X and Y are associated: knowing one changes the distribution of the other. It does not tell us that one causes the other. The χ² statistic is even symmetric in X and Y, so it cannot tell which way an effect would go. An association can come from:

  • Chance. At level α, an independent pair is declared dependent with probability α; testing many pairs, some will come out “significant” by luck.
  • A confounder. A third variable Z influences both X and Y. Students of different ages may prefer different colours because of fashion in the years they grew up, not because age acts on taste.
  • Reverse causation. The effect may go from Y to X instead of from X to Y.
  • Selection. Only some units enter the dataset. An IDS log contains only the attacks the IDS detected, so its rules shape which (attack, service) pairs appear.

A confounder can even reverse an association. Two intrusion detection systems are tested on easy and hard attacks:

detection rateeasy attackshard attacksall attacks
old IDS270 / 300 = 90%40 / 100 = 40%310 / 400 = 77.5%
new IDS95 / 100 = 95%135 / 300 = 45%230 / 400 = 57.5%

The new IDS is better on easy attacks and on hard attacks, yet worse overall, because it was tested mostly on hard attacks (Simpson’s paradox). Looking only at the table “IDS × detected”, the association goes the wrong way; the difficulty of the attack is the confounder. To claim causation we need more than an association: a randomised experiment (here, assigning attacks to the two systems at random), or measuring and controlling the confounders (comparing within each level of Z), together with knowledge of the mechanism.

Core of the computation

// records: array of [i, j], the category indices of X and Y for each unit
const N = Array.from({length: r}, () => new Array(c).fill(0));
for (const [i, j] of records) N[i][j]++;                       // contingency table

const rowSum = N.map(row => row.reduce((s, v) => s + v, 0));   // nᵢ.  (marginal of X)
const colSum = N[0].map((_, j) => N.reduce((s, row) => s + row[j], 0)); // n.ⱼ
const n = rowSum.reduce((s, v) => s + v, 0);

const f      = (i, j) => N[i][j] / n;          // joint relative frequency
const fXgY   = (i, j) => N[i][j] / colSum[j];  // f(xᵢ | yⱼ)
const fYgX   = (i, j) => N[i][j] / rowSum[i];  // f(yⱼ | xᵢ)
const E      = (i, j) => rowSum[i] * colSum[j] / n;  // expected under independence

let chi2 = 0;
for (let i = 0; i < r; i++)
  for (let j = 0; j < c; j++) chi2 += (N[i][j] - E(i, j)) ** 2 / E(i, j);

const df = (r - 1) * (c - 1);
const p  = gammaQ(df / 2, chi2 / 2);           // P(χ²_df ≥ chi2), upper incomplete gamma
const V  = Math.sqrt(chi2 / (n * (Math.min(r, c) - 1)));

The p-value uses the regularised upper incomplete gamma function Q(k/2, x/2) (series for small x, continued fraction for large x, with the Lanczos approximation of ln Γ). Simulations use a seeded generator (mulberry32), so the same seed always gives the same dataset.

Conclusions

  • The contingency table is just a count of the records by pair of categories; the marginal frequencies are its row and column totals, and the conditional frequencies are its columns (or rows) divided by their totals.
  • Independence means that the joint distribution is the product of the marginals, or equally that every conditional profile equals the marginal one. In a sample this never holds exactly, so we compare the observed table with the expected table n*ᵢⱼ = nᵢ. n.ⱼ / n.
  • The χ² statistic measures the distance between the two tables, and its p-value says whether the distance is larger than sampling noise. With λ = 0 the test rejects only about a fraction α of the time (try a few seeds); as λ grows the profiles separate, χ² grows and independence is rejected.
  • The simulation of Part 4 reproduces the χ² distribution, so the approximate p-value can be trusted when the expected counts are not too small.
  • χ² grows with n, so it measures evidence; Cramér’s V measures strength.
  • A significant χ² establishes an association, not a cause: chance, confounders, reverse causation and selection can all produce one, and a confounder can even reverse it (Simpson’s paradox).
