Homework 4 — The Welford recurrence and continuous penetration scores

Statistics — first we derive the online (Welford) update of the mean and of the sum of squared deviations. Then we generalise Homework 3: each attack now gives a score in (0, 10) drawn from a distribution of our choice, and we verify how the mean and variance of the hackers' average scores relate to those of the score distribution. Every mean and variance on this page is computed with the Welford recurrence. All results are simulated live in your browser.

Previous homework: Homework 3 — penetration scores and the Law of Large Numbers.

The assignment

1. Starting from SSn = Σi=1..n (xᵢ − x̄ₙ)², derive the recursive update of the sum of squared deviations (and of the mean), by adding and subtracting the same term x̄ₙ₋₁ inside the square.

2. Take the setup of the previous homework (n systems, m hackers, each hacker attacks the systems one after the other → trajectories), but instead of a score in {0, 1}, each attack gives a score in (0, 10) with some distribution, chosen freely; at each step a score is drawn from it. Compute the mean and variance of the average score of the trajectories and verify their relationship with the mean and variance of the score distribution.

Constraint. The naive formulas Σxᵢ / n for the mean and Σxᵢ²/n − x̄² for the variance must not be used in the code (overflow, catastrophic cancellation). Mean and variance are computed with the Welford recurrence.

Part 1 — Derivation of the Welford recurrence

Notation

x̄ₙ = (1/n) Σi=1..n xᵢ     SSₙ = Σi=1..n (xᵢ − x̄ₙ)²     s²ₙ = SSₙ / (n − 1)

Step 1 — the mean

Split off the last observation:

n x̄ₙ = Σi=1..n−1 xᵢ + xₙ = (n − 1) x̄ₙ₋₁ + xₙ  ⇒  x̄ₙ = x̄ₙ₋₁ + (xₙ − x̄ₙ₋₁) / n

Call δ = xₙ − x̄ₙ₋₁ the deviation of the new value from the old mean. Then the mean moves by x̄ₙ − x̄ₙ₋₁ = δ / n. Two facts follow and are used below:

(a) xₙ − x̄ₙ = δ − δ/n = (n − 1) δ / n     (b) Σi=1..n−1 (xᵢ − x̄ₙ₋₁) = 0

Step 2 — add and subtract x̄ₙ₋₁ inside the square

xᵢ − x̄ₙ = (xᵢ − x̄ₙ₋₁) − (x̄ₙ − x̄ₙ₋₁) = (xᵢ − x̄ₙ₋₁) − δ/n

Squaring and summing over i = 1, …, n:

SSₙ = Σi=1..n (xᵢ − x̄ₙ₋₁)² − 2 (δ/n) Σi=1..n (xᵢ − x̄ₙ₋₁) + n (δ/n)²

Step 3 — simplify the three terms

  • First term: the first n − 1 summands are exactly SSₙ₋₁, and the last one is (xₙ − x̄ₙ₋₁)² = δ². So it equals SSₙ₋₁ + δ².
  • Second term: by (b) the first n − 1 deviations sum to zero, and only the last one, δ, is left. So it equals −2 (δ/n) · δ = −2δ²/n.
  • Third term: n · δ²/n² = δ²/n.

SSₙ = SSₙ₋₁ + δ² − 2δ²/n + δ²/n = SSₙ₋₁ + δ² (n − 1)/n

Result

Using (a), δ (n − 1)/n = xₙ − x̄ₙ, so the same update can be written without fractions. This is the form used in code:

x̄ₙ = x̄ₙ₋₁ + (xₙ − x̄ₙ₋₁) / n     SSₙ = SSₙ₋₁ + (xₙ − x̄ₙ₋₁)(xₙ − x̄ₙ)

The recursion starts from x̄₀ = 0 and SS₀ = 0. At the first step it gives x̄₁ = x₁ and SS₁ = 0, as it should. The variance is s²ₙ = SSₙ / (n − 1), or SSₙ / n for the population version. Each step costs O(1), the data never need to be stored, and the update only involves deviations from the current mean, never the raw sums.

Why the naive formulas are dangerous

Overflow. Σxᵢ grows with n even when the mean stays bounded. With 32-bit integers it wraps around after about 2·10⁹. With floating point it reaches ∞ when the values are large, while the mean itself would be perfectly representable. Welford never forms the sum: it only stores the mean, which stays on the scale of the data.

Catastrophic cancellation. The formula Σxᵢ² − (Σxᵢ)²/n subtracts two huge, almost equal numbers. When the data have a large mean compared to their spread, the significant digits cancel and only rounding errors are left. The result can even be negative. Part 5 — Mean and variance of the average score

At each checkpoint t we have m average scores, one per hacker. Their mean and variance across hackers are computed with the Welford recurrence, updating once per hacker. The expected relationship with the score distribution is

E[X̄ₜ] = μ     Var(X̄ₜ) = σ² / t   ⇔   t · Var(X̄ₜ) = σ²

Part 6 — Theory

Mean and variance of the average score

The scores X₁, …, Xₜ of one hacker are independent and identically distributed with mean μ and variance σ². By linearity of expectation, and since the variance of a sum of independent variables is the sum of the variances:

E[X̄ₜ] = (1/t) · t μ = μ     Var(X̄ₜ) = (1/t²) · t σ² = σ² / t

So the average score is centred on the mean of the score distribution, and its spread shrinks like σ/√t. By Chebyshev, Pr(|X̄ₜ − μ| > ε) ≤ σ²/(tε²) → 0: the weak Law of Large Numbers holds for any score distribution with finite variance, not only for Bernoulli scores. By the CLT, (X̄ₜ − μ)/(σ/√t) → N(0, 1), which is why the histograms in Part 5 are bell-shaped even when the score distribution is skewed or discrete.

Within-trajectory variance

The sample variance s² = SSₙ/(n − 1) is an unbiased estimator of σ²: E[s²] = σ². The divisor n − 1 compensates for measuring deviations from x̄ₙ, which is itself fitted to the same data. So the average of the m values s²ⱼ should be close to σ², and each single s²ⱼ gets closer to σ² as n grows.

Core of the simulation

// Welford update: one observation x into the state {k, mean, ss}
function push(st, x) {
  st.k += 1;
  const delta = x - st.mean;          // x_k − mean_{k−1}
  st.mean += delta / st.k;            // mean_k
  st.ss += delta * (x - st.mean);     // SS_k = SS_{k−1} + (x − mean_{k−1})(x − mean_k)
}

for (let j = 0; j < m; j++) {        // hacker j
  const traj = { k: 0, mean: 0, ss: 0 };
  for (let i = 1; i <= n; i++) {
    push(traj, draw());               // score of attack i, drawn from the chosen distribution
    if (isCheckpoint[i]) push(across[i], traj.mean);   // Welford across hackers
  }
  push(withinVar, traj.ss / (n - 1)); // sample variance of hacker j
}
// across[t].mean ≈ μ  and  across[t].ss / (m − 1) ≈ σ² / t

No sum of the scores and no sum of squares is ever formed. The generator is a seeded PRNG (mulberry32). Beta variates come from two Gamma variates (Marsaglia–Tsang method), so the same seed always reproduces the same results.

Conclusions

  • The Welford recurrence x̄ₙ = x̄ₙ₋₁ + (xₙ − x̄ₙ₋₁)/n, SSₙ = SSₙ₋₁ + (xₙ − x̄ₙ₋₁)(xₙ − x̄ₙ) follows from adding and subtracting x̄ₙ₋₁ inside the square. It is exact, works in a single pass, and avoids the overflow and cancellation of the textbook formulas.
  • For any score distribution with mean μ and variance σ², the average score of a trajectory after t attacks has mean μ and variance σ²/t. The simulation confirms that t · Var(X̄ₜ) stays at σ² for every t.
  • Homework 3 is the special case of a two-valued score. The same LLN and CLT behaviour appears with continuous, skewed and discrete scores.
