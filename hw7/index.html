Part 1 — The four modes of convergence

Let X₁, X₂, … and X be random variables. “Xₙ → X” can mean very different things, because a random variable is a function ω ↦ X(ω) on a probability space (Ω, 𝓕, P), not a number. The four classical modes, from the strongest requirement on single outcomes to the weakest:

Almost sure convergence (with probability 1)

Xₙ → X a.s.  ⇔  P( { ω : Xₙ(ω) → X(ω) } ) = 1
⇔  for every ε > 0: P( supm≥n |Xₘ − X| > ε ) → 0

Pointwise convergence of the functions, except on a set of probability zero. It is a statement about whole trajectories: for almost every outcome the sequence of numbers Xₙ(ω) eventually enters any band around X(ω) and never leaves it again. It is the mode of the Strong LLN (Kolmogorov): if the Xᵢ are i.i.d. with E|X| < ∞, then X̄ₙ → μ almost surely. It is also the mode of the Glivenko–Cantelli theorem (the empirical CDF converges to the true CDF uniformly, a.s.) and of the strong consistency of estimators.

Convergence in probability

Xₙ →ᴾ X  ⇔  for every ε > 0: P( |Xₙ − X| > ε ) → 0

For each fixed large n, a large deviation is unlikely, but nothing prevents a given trajectory from making rare excursions forever, at different times for different ω. It is the mode of the Weak LLN and of the definition of a consistent estimator (θ̂ₙ →ᴾ θ). Comparing the two formulas: a.s. controls the sup over all m ≥ n, in probability controls only the single index n.

Mean-square convergence (quadratic mean, L²)

Xₙ → X in L²  ⇔  E[ (Xₙ − X)² ] → 0   (more generally Lᵖ: E|Xₙ − X|ᵖ → 0)

The average squared distance goes to 0. For an estimator, E[(θ̂ₙ − θ)²] is the mean squared error = bias² + variance, so L² convergence is “MSE-consistency”. For the sample mean of uncorrelated variables with variance σ², E[(X̄ₙ − μ)²] = σ²/n → 0, and Chebyshev’s inequality turns this into the shortest proof of the Weak LLN:

P( |X̄ₙ − μ| > ε ) ≤ E[(X̄ₙ − μ)²] / ε² = σ² / (n ε²) → 0

That is exactly the implication “L² ⇒ in probability” (Markov’s inequality). L² is the mode that needs moments: it says nothing when σ² = ∞.

Convergence in distribution (weak convergence, in law)

Xₙ →ᵈ X  ⇔  Fₙ(x) → F(x) at every x where F is continuous
⇔  E g(Xₙ) → E g(X) for every bounded continuous g

Only the laws converge; the variables need not even live on the same probability space, and Xₙ and X can be far from each other for every ω. It is the mode of the Central Limit Theorem:

Zₙ = √n (X̄ₙ − μ) / σ  →ᵈ  N(0, 1)   i.e.  P(Zₙ ≤ z) → Φ(z) for all z

and of all asymptotic tests and confidence intervals (the χ² test of Homework 6 uses “X² →ᵈ χ²df”).

How they are related

Solid arrows always hold; dashed arrows are partial converses that need an extra condition. There is no implication in either direction between a.s. and L².

Each missing arrow has a counterexample. On Ω = [0, 1] with the uniform probability (ω = a uniform random number):

(d) Convergence in distribution: the CLT

For a fixed n we draw many independent samples and histogram the standardized error Zₙ = √n (X̄ₙ − μ)/σ. The CLT says the histogram approaches the N(0, 1) density, whatever the distribution of the Xᵢ, as long as σ² < ∞.

The Kolmogorov distance sup |Fₙ(z) − Φ(z)| between the empirical CDF of Zₙ and Φ is exactly the quantity that convergence in distribution sends to 0. The Berry–Esseen theorem bounds it by 0.48 · E|X − μ|³ / (σ³ √n): the CLT error itself decreases like 1/√n, faster for symmetric distributions (try Uniform) than for skewed ones (Exponential). With Bernoulli data the distance cannot go below the size of the lattice jumps, also of order 1/√n.

Part 3 — Why √n: additivity of the variance and independence

Everything follows from one identity. For any random variables with finite variance,

Var( X₁ + … + Xₙ ) = Σᵢ Var(Xᵢ) + 2 Σi<j Cov(Xᵢ, Xⱼ)

If the Xᵢ are independent (in fact uncorrelated is enough for this formula) all covariances vanish and variances add: Var(Sₙ) = nσ². Standard deviations do not add — they add in quadrature:

sd(Sₙ) = σ √n   ⇒   sd(X̄ₙ) = σ / √n   (the standard error)

Independent errors partially cancel: n steps of a random walk travel about √n, not n. This fixes the only scaling that gives a non-trivial limit. Dividing Sₙ − nμ by nᵃ:

  • a = 1 (the sample mean): the spread σ n½−1 → 0 — a degenerate limit, the LLN (convergence in probability / a.s. to the constant μ);
  • a = ½: the spread is exactly σ for every n — a non-degenerate limit, the CLT (convergence in distribution to N(0, σ²));
  • a < ½: the spread σ n½−a → ∞ — no limit.

The plot uses the trajectories of Part 2 (change the distribution there). The spread is measured robustly (interquartile range / 1.349, equal to σ for a normal), so it exists even when σ² = ∞.

(Sₙ − nμ) — no scaling (Sₙ − nμ)/√n (Sₙ − nμ)/n = X̄ₙ − μ (log–log)

With heavy tails √n is no longer the right scale: for Pareto(α) with 1 < α < 2 the sum spreads like n1/α (slope 0.67 for α = 1.5), the LLN still holds but the CLT does not, and the limit is a non-normal stable law. For the Cauchy the spread of the sum grows like n (slope 1): X̄ₙ has the same Cauchy distribution as a single observation, and averaging gains nothing.

When independence fails

At the opposite extreme, if all Xᵢ are the same variable, Var(Sₙ) = n²σ² and X̄ₙ = X₁ does not converge at all. Real data are in between. Take a stationary AR(1) process Xₜ = ρ Xₜ₋₁ + √(1−ρ²) εₜ (variance 1, correlation ρᵏ at lag k), a simple model for bursty data such as network traffic or log events. The covariances no longer vanish and

Var(X̄ₙ) = (1/n) [ 1 + 2 Σk=1n−1 (1 − k/n) ρᵏ ]  ≈  (1/n) · (1 + ρ)/(1 − ρ)
⇒   neff = n (1 − ρ)/(1 + ρ)

The rate is still 1/√n, but the constant changes: n correlated observations are worth only neff independent ones. A confidence interval that assumes independence (X̄ ± 1.96/√n) is then too narrow and its real coverage falls below 95%.

simulated sd(X̄ₙ) exact formula above 1/√n (independence)

√n in statistical inference

  • Standard errors and intervals. SE(X̄) = σ/√n, estimated by S/√n; the interval X̄ ± z S/√n is justified by the CLT plus Slutsky’s theorem (S →ᴾ σ, so replacing σ by S does not change the limit in distribution).
  • Sample size. Precision grows only like √n: halving the width of an interval costs four times the data; the n needed for a margin E is (zσ/E)².
  • Estimators. “√n-consistency” is the standard: under regularity, √n(θ̂MLE − θ) →ᵈ N(0, I(θ)⁻¹), and the delta method gives √n(g(θ̂) − g(θ)) →ᵈ N(0, g′(θ)² I(θ)⁻¹).
  • Tests. Test statistics have the form √n(θ̂ₙ − θ₀)/s: for a fixed true effect they grow like √n, so with enough data any effect, however small, becomes “significant” (the same reason χ² grows with n in Homework 6).
  • Monte Carlo. The error of a simulation estimate decreases like 1/√R, which is why the curves of Part 2 get smoother only slowly as R grows.
  • Beyond the CLT. The law of the iterated logarithm says the trajectories of Sₙ − nμ reach ±σ√(2n log log n) infinitely often: just a bit more than √n.

Part 4 — Conditional probability and Bayes’ theorem

For events A, B with P(B) > 0, the probability of A given B is

P(A | B) = P(A ∩ B) / P(B)

Conditioning on B means: restrict the sample space to B and renormalize. The conditional frequencies of a contingency table (nᵢⱼ / n.ⱼ in Homework 6) are its empirical counterpart. From the definition come the multiplication rule P(A ∩ B) = P(A | B) P(B), the law of total probability for a partition H₁, …, Hₖ, and Bayes’ theorem, which reverses the direction of the conditioning:

P(Hⱼ | E) = P(E | Hⱼ) P(Hⱼ) / Σₖ P(E | Hₖ) P(Hₖ)
odds form:   P(H|E)/P(Hᶜ|E) = [ P(E|H)/P(E|Hᶜ) ] × P(H)/P(Hᶜ)

Posterior odds = likelihood ratio × prior odds. In statistics the two directions have different roles: classical (frequentist) inference works with P(data | hypothesis) — sampling distributions, p-values — while Bayesian inference computes P(hypothesis | data). Confusing the two (reading a p-value as the probability that H₀ is true) is the prosecutor’s fallacy.

Example: how much should we trust an alarm?

An intrusion detection system flags malicious connections. It detects an attack with probability P(alarm | attack) = sensitivity and raises a false alarm on benign traffic with probability P(alarm | benign) = false-positive rate. The prior is the base rate: the fraction of connections that are attacks.

Part 5 — Prior, likelihood, posterior: Bayesian inference on a parameter

Bayesian inference applies Bayes’ theorem to an unknown parameter θ, treated as a random variable. The three components:

  • Prior π(θ): what is believed about θ before seeing the data — results of previous studies, expert knowledge, physical constraints, or a deliberately vague default.
  • Likelihood L(θ; x) = f(x | θ): the probability of the observed data as a function of θ. It is not a density in θ (it need not integrate to 1); it carries all the information the data give about θ, and it is the same function maximized by the MLE.
  • Posterior π(θ | x): the updated belief,
π(θ | x) = f(x | θ) π(θ) / m(x),    m(x) = ∫ f(x | θ) π(θ) dθ
i.e.   posterior ∝ likelihood × prior

The evidence m(x) is just the normalizing constant (it matters for comparing models, through Bayes factors). The posterior is the whole answer: point estimates (posterior mean, median, mode), credible intervals, probabilities of hypotheses and predictions all come from it.

Updating

With independent observations, the posterior after n − 1 data points is the prior for the n-th: π(θ | x₁…xₙ) ∝ f(xₙ | θ) · π(θ | x₁…xₙ₋₁). Updating one point at a time, in any order, or all at once gives the same result. Learning is cumulative: yesterday’s posterior is today’s prior. This is why Bayes’ theorem is the core of Bayesian inference: it is the single rule that turns information into belief.

Example: the click rate of a phishing campaign (Beta–Binomial)

A company runs a simulated phishing campaign; p is the probability that an employee clicks. Each employee is a Bernoulli(p) trial, so with k clicks out of n the likelihood is L(p) ∝ pᵏ (1 − p)ⁿ⁻ᵏ. With a Beta(a, b) prior the posterior is again a Beta (a conjugate prior):

p ~ Beta(a, b),   k | p ~ Bin(n, p)  ⇒  p | k ~ Beta(a + k, b + n − k)
E[p | k] = (a + k)/(a + b + n) = w · a/(a+b) + (1 − w) · k/n,    w = (a + b)/(a + b + n)

The posterior mean is a weighted average of the prior mean and the MLE k/n; the prior counts as a + b “pseudo-observations” (a clicks and b non-clicks seen before).

The width of the bands shrinks like 1/√n: the posterior sd of p is √(p(1−p)/n) for large n, the same as the frequentist standard error. This is the Bernstein–von Mises theorem — for large n the posterior is approximately N(θ̂MLE, I(θ)⁻¹/n), whatever the (smooth, positive) prior — and it brings us back to Part 3.

Part 6 — More examples, advantages and limitations

Normal data with a normal prior

If X₁…Xₙ | θ ~ N(θ, σ²) with σ known and θ ~ N(μ₀, τ₀²), then θ | x ~ N(μₙ, τₙ²) with

1/τₙ² = 1/τ₀² + n/σ²,    μₙ = τₙ² ( μ₀/τ₀² + n x̄/σ² )

Precisions (inverse variances) add, exactly like the variances of independent variables in Part 3; the posterior mean is the precision-weighted average of the prior mean and x̄, and for large n, τₙ ≈ σ/√n.

Other uses of priors and likelihoods

  • Diagnostic tests and alarms (Part 4): the prior is the base rate; ignoring it (the base-rate fallacy) makes a 99% accurate test look far more conclusive than it is.
  • Spam filtering (naive Bayes). P(spam | words) ∝ P(spam) · Πᵢ P(wordᵢ | spam): the prior is the share of spam, the likelihood comes from word frequencies in labelled mail, and the filter updates as users mark messages.
  • Rare events with zero counts. 0 incidents in n audits gives MLE p̂ = 0, an unrealistic “impossible”; the posterior Beta(1, n + 1) gives mean 1/(n + 2) and a sensible upper bound (about 3/n, like the “rule of three”).
  • A/B testing of two versions of a page or a warning message: the quantity of interest is directly P(pB > pA | data).
  • Forensic evidence: experts are asked to report a likelihood ratio, leaving the prior odds to the court.
  • Hierarchical models: many related groups (departments, servers) share a common prior estimated from the data, so small groups borrow strength from large ones.

Advantages

  • Uses information available before the data, explicitly and transparently.
  • Direct probability statements: “P(p > 0.15 | data) = 0.3” or “p is in [a, b] with probability 95%”, which is what people usually think a confidence interval means.
  • Natural sequential updating, no need to fix n in advance.
  • Works with small samples and zero counts; the posterior expected loss gives a coherent rule for decisions.

Limitations

  • The prior is a choice, and with little data it drives the result (the sensitivity table above). Conclusions should be reported with a sensitivity analysis.
  • A confident wrong prior needs a lot of data to be corrected (the Beta(90, 10) prior); a prior that gives probability 0 to a value can never be revived by any data (Cromwell’s rule).
  • “Non-informative” priors are not unique: uniform on p is not uniform on the log-odds; Jeffreys’ prior is one principled answer. Improper priors can give improper posteriors.
  • The evidence integral is rarely available in closed form: outside conjugate models we need numerical methods (MCMC, variational approximations).
  • The likelihood is a model too: if it is wrong (e.g. assuming independence for correlated data, Part 3), the posterior is confidently wrong, exactly as a frequentist interval would be.

Conclusions

  • The four modes ask different things: a.s. is about whole trajectories, in probability about one fixed n, L² about the average squared error, in distribution only about the laws. a.s. and L² each imply convergence in probability, which implies convergence in distribution; the counterexamples show that none of these arrows can be reversed in general.
  • The LLN says where X̄ₙ goes (μ, in probability or a.s.); the CLT says how it fluctuates around μ (normal, of size σ/√n, in distribution). Part 2(b) shows the difference between weak and strong law: the probability of being outside the band now, and of ever being outside it again, both go to 0, but they are different curves.
  • √n comes from the additivity of variance for independent (uncorrelated) terms: sd(Sₙ) = σ√n. It is the only normalization with a non-degenerate limit, it fixes the rate of standard errors, intervals, tests and Monte Carlo, and it changes when its hypotheses fail: n1/α with heavy tails, a different constant (neff) with dependence.
  • Bayes’ theorem turns P(data | θ) into P(θ | data): posterior ∝ likelihood × prior. With rare events the prior (base rate) dominates the conclusion of a single alarm; repeated independent evidence multiplies the odds by the likelihood ratio each time.
  • In the Beta–Binomial model the posterior mean is a compromise between the prior mean and the MLE with weight (a + b)/(a + b + n); with little data the prior matters a lot, with much data all reasonable priors agree and the posterior concentrates at the rate 1/√n.
