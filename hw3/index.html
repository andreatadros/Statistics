Homework 3 — Penetration scores and the Law of Large Numbers

Statistics — n systems, m hackers. Each attack is a Bernoulli trial. We study the distribution of three penetration scores as n → ∞, and verify that the probability mass of the relative frequency concentrates on p. All results are simulated live in your browser.

The assignment

Given n systems and m hackers, generate for n → ∞ the distribution of the penetration scores

(1) ΣXᵢ / n     (2) ΣXᵢ     (3) ΣXᵢ / √n     with Xᵢ ∈ {0, 1}  and  Xᵢ ∈ {−1, +1}

Verify that the probability mass concentrates on p as n → ∞, where p = Pr(Xᵢ = 1), in the case of the relative frequency ΣXᵢ / n.

Model. Hacker j (j = 1…m) attacks the systems one after the other. Attack i succeeds (Xᵢ = 1) with probability p, independently of all the others. On failure, Xᵢ = 0 in the first encoding, or Xᵢ = −1 (a penalty) in the second one. The sequence of partial scores of one hacker, for i = 1, 2, …, n, is that hacker's trajectory.

Part 3 — Verification: the mass concentrates on p

Let fₙ = (number of successes) / n be the relative frequency of successful attacks. Convergence in probability means that for every ε > 0

Pr( |fₙ − p| > ε ) → 0   as n → ∞

We estimate this probability as the fraction of the m hackers whose frequency lies outside the band p ± ε, and compare it with the Chebyshev bound and with the normal approximation.

observed fraction outside p ± ε Chebyshev bound p(1−p)/(nε²) normal approximation

Part 4 — Theory

Mean and variance of a single attack

With success value 1 and failure value a (a = 0 or a = −1):

μ = E[Xᵢ] = p·1 + (1−p)·a     σ² = Var(Xᵢ) = (1−a)²·p(1−p)

  • Xᵢ ∈ {0, 1}: μ = p, σ² = p(1−p).
  • Xᵢ ∈ {−1, +1}: μ = 2p − 1, σ² = 4p(1−p).

The three scores

Since the attacks are independent, E[ΣXᵢ] = nμ and Var(ΣXᵢ) = nσ². Dividing by a constant c divides the mean by c and the variance by c²:

scoremeanstandard deviationas n → ∞
(1) ΣXᵢ / nμσ / √nsd → 0: concentrates on μ
(2) ΣXᵢnμσ √nsd → ∞: spreads out
(3) ΣXᵢ / √n√n μσsd constant: stable shape

Dividing by n is too strong (everything collapses), not dividing is too weak (everything explodes), and dividing by √n is the scaling that keeps the width fixed.

Why the relative frequency converges to p (weak LLN)

Chebyshev's inequality states that for any random variable Y with finite variance, Pr(|Y − E[Y]| > ε) ≤ Var(Y) / ε². Applied to the relative frequency fₙ, with E[fₙ] = p and Var(fₙ) = p(1−p)/n:

Pr( |fₙ − p| > ε ) ≤ p(1−p) / (n ε²) → 0   as n → ∞

This holds for every ε > 0, which is exactly the definition of convergence in probability: fₙ → p. In the {−1, +1} encoding the score is ΣXᵢ/n = 2fₙ − 1, so it concentrates on 2p − 1, and equivalently the frequency of successes concentrates on p.

Why the √n scaling gives a bell curve (CLT)

The Central Limit Theorem says that (ΣXᵢ − nμ) / (σ√n) converges in distribution to N(0, 1). With Xᵢ ∈ {−1, +1} and p = 0.5 we have μ = 0 and σ = 1, so score (3) is exactly this quantity: ΣXᵢ / √n → N(0, 1). In the other cases score (3) has the same bell shape and constant width, but its centre √n μ moves as n grows.

Deterministic limit vs. limit in probability

For an ordinary function, f(x) → L means: for every ε > 0 there is x₀ such that |f(x) − L| < ε for every x > x₀. A single trajectory of a hacker is random, so no x₀ can guarantee that every trajectory stays inside the band. Convergence in probability asks for less: at step n, the probability (the fraction of trajectories) outside the band goes to zero.

Core of the simulation

// m hackers, n systems, success probability p, failure value a (0 or -1)
for (let j = 0; j < m; j++) {
  let successes = 0;
  for (let i = 1; i <= n; i++) {
    if (rand() < p) successes++;          // X_i = 1 with probability p
    if (isCheckpoint[i]) {
      const S = successes + (i - successes) * a;   // sum of X_1..X_i
      record(j, i, S / i, S, S / Math.sqrt(i));    // scores (1), (2), (3)
    }
  }
}

The generator is a seeded PRNG (mulberry32), so the same seed always reproduces the same results.

Conclusions

  • The relative frequency ΣXᵢ/n concentrates on its mean: on p with Xᵢ ∈ {0, 1}, on 2p − 1 with Xᵢ ∈ {−1, +1}. The fraction of hackers outside p ± ε falls towards zero, always below the Chebyshev bound. This is the weak Law of Large Numbers, i.e. convergence in probability.
  • The raw score ΣXᵢ spreads out like √n: the trajectories open like a fan.
  • The score ΣXᵢ/√n keeps a constant width and a bell shape, as predicted by the Central Limit Theorem.
