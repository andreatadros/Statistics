Homework 5 — From density to CDF, and Riemann vs Lebesgue integration

Statistics — first we build the cumulative distribution function of a normal random variable by integrating its density numerically, and use it to see how the two functions are related. Then we compute the same integrals in two different ways, slicing the area under a function vertically (Riemann) or horizontally (Lebesgue), and compare how the two methods behave on different functions. The assignment

1. Given a normal density, find the CDF by numerical integration. This shows in practice the relationship between the density and the cumulative distribution function.

2. Given a choice of functions f₁, f₂, compute numerically both the Riemann and the Lebesgue integral. This shows in practice the difference between the two.

Part 1 — The CDF of a normal density, by numerical integration

The method

The density of N(μ, σ²) and its CDF are

f(x) = 1/(σ√(2π)) · exp(−(x − μ)² / (2σ²))     F(x) = Pr(X ≤ x) = ∫−∞..x f(t) dt

F has no closed form, so we integrate. The integral starts at −∞, but we start at a = μ − 10σ, where the missing mass is Φ(−10) ≈ 7.6 · 10⁻²⁴, far below double precision. On the nodes xᵢ = a + i·h we accumulate the area strip by strip, either with rectangles or with trapezoids:

rectangles: F(xᵢ₊₁) = F(xᵢ) + f(xᵢ) · h     trapezoids: F(xᵢ₊₁) = F(xᵢ) + h · (f(xᵢ) + f(xᵢ₊₁)) / 2

Each value of F is the previous one plus the area of one strip f(x)·dx: the CDF is the running total of the density. The result is compared with the exact CDF Φ((x − μ)/σ), computed from the error function to full double precision.

The dots are computed from the CDF alone, by taking its slope, and they fall back onto the density: integrating f gives F, differentiating F gives back f.

Moments as integrals with respect to F: ∫ x dF → μ, σ

Once F is known on the grid, the increment F(xᵢ₊₁) − F(xᵢ) is the probability of the strip [xᵢ, xᵢ₊₁]. Weighting each strip by its midpoint x̃ᵢ gives the Stieltjes sums

μ ≈ Σ x̃ᵢ · (F(xᵢ₊₁) − F(xᵢ))     σ² ≈ Σ (x̃ᵢ − μ̂)² · (F(xᵢ₊₁) − F(xᵢ))

Part 2 — Riemann and Lebesgue integrals of f₁ and f₂

Two ways to slice the same area

Riemann cuts the domain (the x-axis) into n strips of width Δx and asks, for each strip, “how high is f here?”:

Rₙ = Σi=1..n f(ξᵢ) · Δx     (ξᵢ = midpoint of strip i)

Lebesgue cuts the range (the y-axis) into K levels of height Δy and asks, for each level, “on how much of the x-axis is f above this level?”. That amount is the measure m({x : f(x) > y}), and the integral is the area under it (the “layer cake” formula, for f ≥ 0):

∫ f dm = ∫0..∞ m({x : f(x) > y}) dy  ≈  LK = Σj=1..K m({f > yⱼ}) · Δy     (yⱼ = midpoint of level j)

The set {f > y} can be made of many separate pieces: Lebesgue does not care where they are, only how long they are in total. To measure them, the page samples f once on a fine “measuring tape” of M = 2²⁰ ≈ 10⁶ points and sorts the values. The measure of {f > y} is then (number of samples above y) × (b − a)/M, found by binary search.

Part 3 — Theory

Density and CDF

For a continuous random variable the two functions carry the same information:

F(x) = ∫−∞..x f(t) dt   ⇔   f(x) = F′(x)     Pr(a < X ≤ b) = F(b) − F(a) = ∫a..b f(x) dx

The density is not a probability (it can exceed 1 when σ is small): only areas under it are probabilities, and F(x) is the area to the left of x. F is non-decreasing, goes from 0 to 1, and it is steepest exactly where f is largest.

Error of the two rules in Part 1

On one strip, the left rectangle misses the area of a triangle, about h²·f′/2, and the trapezoid misses about h³·f″/12. Summing over the strips up to x gives

rectangles: Fh(x) − F(x) ≈ −(h/2)·f(x)     trapezoids: Fh(x) − F(x) ≈ +(h²/12)·f′(x)

So the largest error is about h·max f / 2 = h / (2σ√(2π)) for rectangles and h²·max|f′| / 12 = h² / (12σ²√(2πe)) for trapezoids. These are the predicted values in the table of Part 1.

The same strip picture explains the moments table. With rectangles, the probability f(xᵢ)·h of the node xᵢ is assigned to the strip on its right, so the whole distribution is moved by h/2 and the computed mean is μ + h/2, while the variance stays σ². With trapezoids, half of it goes to each side, so the mean is exact but the mass is spread by ±h/2 and the variance grows by (h/2)² = h²/4. Both biases vanish as h → 0.

Riemann and Lebesgue

Riemann partitions the domain. The integral exists when the upper sums (largest value on each strip) and the lower sums (smallest value) converge to the same number. That happens exactly when f is bounded and its points of discontinuity have measure zero.

Lebesgue partitions the range. For a simple function s = Σ cⱼ·1Aⱼ the integral is Σ cⱼ·m(Aⱼ), value times measure of the set where it is taken; for f ≥ 0 the integral is the supremum over the simple functions below f, which is the layer-cake formula used above. Every Riemann-integrable function is Lebesgue-integrable with the same value, so on the functions of Part 2 the two methods must agree in the limit. What changes is how they get there:

  • The Riemann error depends on how irregular f is in x: fast oscillations or steep parts need many strips.
  • The Lebesgue error depends on how the measure m({f > y}) changes in y. Where it is smooth, few levels suffice. The sum is always between the lower and upper Lebesgue sums, which differ by at most Δy·(b − a), no matter how much f oscillates.
  • For a function with finitely many values (the staircase), m({f > y}) is a step function, and the Lebesgue sum is exact as soon as no level falls exactly on a value.
  • x² and √x on [0, 1] are inverse functions: the graph of one is the graph of the other reflected across the line y = x. The vertical strips of one are the horizontal slices of the other, so the Riemann error of x² equals the Lebesgue error of √x, and vice versa. The comparison table shows the two errors are equal until the tape accuracy is reached.

Where only Lebesgue works

The Dirichlet function, 1 on the rationals of [0, 1] and 0 elsewhere, has upper sums equal to 1 and lower sums equal to 0 on every partition, because every strip contains both rationals and irrationals: it is not Riemann integrable. For Lebesgue it is a simple function: the rationals are countable, so m(ℚ ∩ [0, 1]) = 0 and the integral is 1·0 + 0·1 = 0. It cannot be shown on a computer: every floating-point number is rational, so a program would only ever see the value 1.

The link with probability

Probability theory is built on the Lebesgue integral. The expected value is E[X] = ∫ x dF(x), a Lebesgue–Stieltjes integral with respect to the CDF. It covers continuous, discrete and mixed distributions with one formula: dF = f(x) dx when there is a density, and dF is a jump of size Pr(X = x) at an atom. For X ≥ 0 the layer-cake formula becomes

E[X] = ∫0..∞ Pr(X > y) dy = ∫0..∞ (1 − F(y)) dy

which is the probabilistic form of Lebesgue's horizontal slicing. The right-hand charts of Part 2 are exactly this: if U is uniform on [a, b], then m({f > y}) = (b − a) · Pr(f(U) > y). Sorting the tape gives the quantile function of f(U), and the Lebesgue integral equals (b − a) · E[f(U)].

Core of the computation

// Part 1: CDF of N(mu, sigma²) by accumulating strips f(x) dx
const a = mu - 10 * sigma, N = Math.round(20 * sigma / h);
F[0] = 0;
for (let i = 1; i <= N; i++) {
  const x0 = a + (i - 1) * h, x1 = a + i * h;
  F[i] = F[i - 1] + (rule === "rect" ? f(x0) * h               // rectangle
                                     : h * (f(x0) + f(x1)) / 2); // trapezoid
}

// Part 2: Riemann — slice the x-axis
function riemann(f, a, b, n) {
  const dx = (b - a) / n; let s = 0;
  for (let i = 0; i < n; i++) s += f(a + (i + 0.5) * dx);
  return s * dx;
}

// Part 2: Lebesgue — slice the y-axis
// tape = f sampled at M midpoints of [a, b], sorted increasingly
const measureAbove = y => countAbove(tape, y) * (b - a) / M;   // m({f > y}), binary search
function lebesgue(top, K) {                                       // 0 ≤ f ≤ top
  const dy = top / K; let s = 0;
  for (let j = 0; j < K; j++) s += measureAbove((j + 0.5) * dy);
  return s * dy;
}

The exact CDF uses erf (power series for |x| < 2.5, continued fraction for erfc beyond); the exact integral of sin²(1/x) uses the sine integral Si(2) (power series). Both are accurate to about 10⁻¹⁵.

Conclusions

  • Integrating the normal density strip by strip gives its CDF: each value of F is the area accumulated so far. Taking the slope of the computed CDF gives the density back, so the two are two views of the same distribution.
  • Rectangles converge like h and trapezoids like h², as predicted. From the computed CDF, the sums ∫ x dF and ∫ (x − μ)² dF recover μ and σ², with biases h/2 and h²/4 that vanish as h → 0.
  • Riemann and Lebesgue give the same value on these functions, but they get there differently: Riemann slices the x-axis and suffers when f oscillates or is steep in x; Lebesgue slices the y-axis and only depends on how much of the domain lies above each level.
  • Probability uses Lebesgue's point of view: expectations are integrals with respect to the distribution, E[X] = ∫ x dF, and for X ≥ 0 they are areas of horizontal slices, ∫ Pr(X > y) dy.
